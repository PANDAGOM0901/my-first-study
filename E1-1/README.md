# 내 컴퓨터에 개발자용 '작업실' 꾸미기


## 프로젝트 개요
핵심 도구인 리눅스 CLI(터미널), Docker(컨테이너), Git/GitHub(버전 관리 및 협업)를 함께 사용하여 코드가 "내 컴퓨터에서만" 돌아가는 문제를 줄이고, 팀원 누구나 같은 방식으로 실행, 배포, 디버깅할 수 있는 환경 구성을 목표로 합니다.

이 미션에서는 터미널로 작업 디렉토리와 권한을 정리한 뒤, Docker를 설치 및 점검하고 컨테이너를 실행/관리합니다.

이어서 간단한 웹 서버를 Dockerfile로 컨테이너화하고, 포트 매핑으로 접속을 확인하며, 바인드 마운트/볼륨으로 "변경 반영"과 "데이터 영속성"을 직접 검증합니다.
## 실행 환경
OS: MacOS Sequoia 버전 15.7.4(24G517)

Shell: zsh 5.9 (x86_64-apple-darwin24.0)

Docker: Docker version 28.5.2

Git: git version 2.53.0
