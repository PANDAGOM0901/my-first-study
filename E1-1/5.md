### 컨테이너 종료 및 유지
#### 컨테이너 종료
Ubuntu 컨테이너 안에서:
```bash
exit
```
컨테이너가 종료되고 호스트의 터미널로 돌아옴

실행 중인 컨테이너를 확인하려면:
```bash
docker ps
```
종료된 컨테이너까지 확인하려면:
```bash
docker ps -a
```
![alt text](image_files/스크린샷%202026-08-15%20오후%204.43.43.png)
여기서 방금 실행했던 Ubuntu 컨테이너가 Exited 상태로 표시
#### 컨테이너 유지 - attach / exec
exit는 현재 컨테이너의 메인 프로세스(bash 등)를 끝내므로 컨테이너가 종료될 수 있음.
```
attach = 기존 프로세스에 연결

exec = 새로운 프로세스를 실행
```
Docker에서 attach와 exec의 차이는 “실행 중인 컨테이너의 어떤 프로세스에 연결하느냐”로 이해
| 구분                | `docker attach`       | `docker exec`           |
| ----------------- | --------------------- | ----------------------- |
| 대상                | 컨테이너의 **기존 메인 프로세스**  | 컨테이너에서 **새로 실행하는 프로세스** |
| 새로운 프로세스 생성       | ❌                     | ✅                       |
| 컨테이너의 메인 프로세스와 연결 | ✅                     | ❌                       |
| 셸에 들어갈 때          | 기존 셸에 연결              | 새로운 셸 생성                |
| `exit`의 영향        | 메인 프로세스를 종료시킬 수 있음    | 새로 만든 셸만 종료             |
| 주 용도              | 실행 중인 컨테이너의 출력/입력에 연결 | 실행 중 컨테이너에서 명령 실행       |
| 일반적인 디버깅/관리       | 상대적으로 위험              | 일반적으로 더 편리하고 안전         |
#### docker attach
```
컨테이너
└── bash   ← 컨테이너의 메인 프로세스
```
```bash
docker attach my-ubuntu
```
```
터미널 A
   │
   ▼
┌─────────────────┐
│ Ubuntu 컨테이너   │
│                 │
│ bash (PID 1)    │◄──── 터미널 B
└─────────────────┘
```
#### docker exec
```
컨테이너
└── bash   ← 컨테이너의 메인 프로세스
```
```bash
docker exec -it my-ubuntu
```
```
┌───────────────────┐
│ Ubuntu 컨테이너     │
│                   │
│ bash (PID 1)      │← 원래 실행 중
│                   │
│ bash (새로운 프로세스)│← exec
└───────────────────┘
```
"my-ubuntu 컨테이너 안에서 프로세스 하나 새로 실행해 줘."
##### attach는 언제 사용하는가?
attach는 컨테이너의 메인 프로세스와 직접 상호작용해야 할 때 사용

컨테이너가 실행하고 있는 프로그램의 표준 입력(stdin), 출력(stdout), 오류(stderr)에 연결할 수 있고, 따라서 그 프로그램의 터미널 출력을 직접 보거나 입력을 전달해야 하는 상황에서 의미가 있음
##### exe은 언제 사용하는가?
실무에서는 exec을 훨씬 자주 사용

원래 컨테이너의 메인 프로세스에 영향을 주지 않고 별도의 셸을 사용할 수 있으므로 컨테이너에서 문제가 발생한 상황에서도 실행 중인 컨테이너를 확인한 뒤 컨테이너 내부에서 새로운 프로세스를 실행하여 명령어를 실행하면서 상태를 확인할 수 있음

### 실습 결과를 정리하면:
docker attach는 실행 중인 컨테이너의 기존 메인 프로세스에 연결하는 방식이고, docker exec는 실행 중인 컨테이너 내부에서 새로운 프로세스를 실행하는 방식이다. 

따라서 exec로 실행한 bash에서 exit하면 새로 생성된 bash만 종료되고 컨테이너는 계속 실행되지만, attach로 메인 프로세스에 연결된 상태에서 exit하면 메인 프로세스가 종료되어 컨테이너도 종료될 수 있다. 

attach에서 컨테이너를 유지하면서 빠져나오려면 Ctrl-p, Ctrl-q를 사용할 수 있다.
