### ubuntu 컨테이너 실행 및 내부 진입
```bash
docker run -it ubuntu
```
```
docker → Docker 프로그램 실행
run → 새 컨테이너를 만들어 실행
-i → 컨테이너의 입력을 계속 받을 수 있게 함 (interactive)
-t → 터미널 환경을 만들어 줌 (TTY)
ubuntu → 사용할 Ubuntu 이미지
```
