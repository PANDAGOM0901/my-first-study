## Docker 설치 및 기본 점검

### Docker 버전 확인
다음 명령어를 실행하여 Docker 설치 및 버전을 확인한다.

명령어:
```bash
docker --version
```
점검 결과:
![alt text](image_files/스크린샷%202026-08-11%20오후%206.12.27.png)
→ Docker가 정상적으로 설치되어 있으며, 위와 같이 버전 정보가 출력되는 것을 확인하였다.

### Docker 데몬 동작 여부 확인
다음 명령어를 실행하여 Docker Engine(Docker 데몬)과 정상적으로 연결되는지 확인한다.

명령어:
```bash
docker info
```
점검 결과:
![alt text](image_files/스크린샷%202026-08-11%20오후%206.19.11.png)
→ Server 정보가 정상적으로 출력되어 Docker Engine이 정상적으로 동작하고 있음을 확인하였다.

최종 점검 결과:

Docker 설치 및 Docker Engine 동작 상태가 정상임을 확인하였다.
