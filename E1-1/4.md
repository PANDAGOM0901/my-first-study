## Docker 기본 운영 명령 수행

### Docker 이미지 다운로드 및 목록 확인
#### Docker 이미지 다운로드
명령어:
```bash
docker pull hello-world
```
수행 결과:
![alt text](image_files/스크린샷%202026-08-11%20오후%206.28.40.png)
#### Docker 이미지 목록 확인
명령어:
```bsh
docker images
또는
docker image ls
```
출력 결과:
![alt text](image_files/스크린샷%202026-08-11%20오후%206.37.58.png)
![alt text](image_files/스크린샷%202026-08-11%20오후%206.38.33.png)
→ hello-world 이미지가 정상적으로 다운로드되어 이미지 목록에 표시되는 것을 확인하였다.

### 컨테이너 실행/중지/목록 확인
#### 컨테이너 실행 및 목록 확인
다운로드한 이미지를 이용하여 컨테이너를 실행한다.

명령어:
```bash
docker run hello-world
```
수행 결과:
![alt text](image_files/스크린샷%202026-08-11%20오후%206.45.21.png)

실행 중인 컨테이너 확인하기
```bash
docker ps
```
전체 컨테이너 확인하기(종료된 컨테이너 포함)
```bash
docker ps -a
```
![alt text](image_files/스크린샷%202026-08-11%20오후%206.49.27.png)
→ hello-world 컨테이너가 정상적으로 실행된 후 Exited (0) 상태로 종료된 것을 확인하였다.
#### 컨테이너 중지
명령어:
```bash
docker stop [컨테이너ID]
```
![alt text](image_files/스크린샷%202026-08-11%20오후%206.56.42.png)
→ 컨테이너가 정상적으로 중지되었음을 확인하였다.

### 컨테이너 운영
#### 컨테이너 로그 확인
명령어:
```bash
docker logs [컨테이너ID]
```
출력 결과:
![alt text](image_files/스크린샷%202026-08-11%20오후%207.05.58.png)
→ docker logs 명령을 통해 컨테이너의 실행 결과 및 로그를 확인하였다.
#### 컨테이너 리소스 확인
실행 중인 컨테이너의 CPU, 메모리 등의 리소스 사용량을 확인한다.

명령어:
```bash
docker stats
```
수행 결과:
![alt text](image_files/스크린샷%202026-08-11%20오후%207.09.56.png)
→ docker stats 명령을 통해 실행 중인 컨테이너의 CPU 및 메모리 등 리소스 사용량을 확인하였다.

최종 점검 결과:

Docker 이미지의 다운로드 및 목록 확인, 컨테이너의 실행·중지·목록 확인, 컨테이너 로그 확인 및 리소스 사용량 확인 명령을 수행하여 Docker의 기본 운영 기능을 점검하였다.
