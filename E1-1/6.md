## 기존 Dockerfile 기반 커스텀 이미지 제작

### Dockerfile
Dockerfile: Docker 이미지를 만들기 위한 설계도(설정 파일)

- Dockerfile은 내가 원하는 Docker 이미지를 어떤 재료와 설정으로 만들 것인지 Docker에게 알려주는 텍스트 파일
### (A) 웹 서버 베이스 이미지 활용 + 정적 콘텐츠/설정만 교체
본 실습에서는 웹 서버 베이스 이미지를 활용하는 A 방식을 선택

 기존 NGINX 이미지를 그대로 사용하는 것이 아니라 우리가 직접 만든 HTML과 설정을 포함한 새로운 이미지 만들기
```
기존 NGINX 이미지
      ↓
Dockerfile 작성
      ↓
index.html 추가
      ↓
커스텀 이미지 빌드
      ↓
컨테이너 실행
      ↓
웹 브라우저 접속
```
| 요구사항          | 우리가 하는 작업               |
| ------------- | ----------------------- |
| 기존 베이스 이미지 사용 | `nginx:alpine`          |
| 커스텀 이미지 제작    | Dockerfile 작성           |
| 정적 콘텐츠 변경     | `index.html` 추가         |
| 이미지 빌드        | `docker build`          |
| 컨테이너 실행       | `docker run`            |
| 실행 확인         | `docker ps`             |
| 웹 서버 확인       | `localhost:8080`        |
| 기술 문서         | Dockerfile + 명령어 + 스크린샷 |
#### 파일 구조
```
docker-web-workstation/
├── Dockerfile
└── index.html
```

#### Dockerfile 만들기
```bash
nano Dockerfile
```
Dockerfile에 다음 내용 입력
```
FROM nginx:alpine

LABEL maintainer="student"
LABEL description="Custom NGINX web server"

COPY index.html /usr/share/nginx/html/index.html

EXPOSE 80

HEALTHCHECK --interval=30s --timeout=3s \
    CMD wget --no-verbose --tries=1 --spider http://localhost/ || exit 1
```

#### Dockerfile 이해하기
① 기존 베이스 이미지
```dockerfile
FROM nginx:alpine
```
② 이미지 설명
```dockerfile
LABEL maintainer="student"
LABEL description="Custom NGINX web server"
```
③ HTML 파일 커스터마이징
```dockerfile
COPY index.html /usr/share/nginx/html/index.html
```
index.html을 Docker 이미지 내부의 Nginx 웹 루트로 복사

기존 Nginx 페이지 대신 직접 커스텀 한 웹페이지가 표시됨
④ 포트
```dockerfile
EXPOSE 80
```
컨테이너 내부의 웹 서버가 HTTP 80 포트를 사용한다는 의미
⑤ Health Check
```dockerfile
HEALTHCHECK ...
```
Nginx가 실제로 HTTP 응답을 하고 있는지 확인

#### Docker 이미지 빌드
```bash
docker build -t custom-web:1.0 .
```
Docker는 Dockerfile을 읽고 다음 작업을 수행
```
nginx:alpine 다운로드
        ↓
LABEL 적용
        ↓
index.html 복사
        ↓
EXPOSE 80 설정
        ↓
HEALTHCHECK 설정
        ↓
custom-web:1.0 생성
```

#### 컨테이너 실행 및 실행 확인
```bash
docker run -d --name custom-web -p 8080:80 custom-web:1.0
```
```

--name custom-web: 컨테이너 이름 지정

-p 8080:80: Mac의 8080 포트를 컨테이너의 80 포트에 연결

custom-web:1.0: 방금 만든 이미지 사용
```

## 포트 매핑 및 접속 증거

컨테이너의 NGINX 웹 서버는 80번 포트를 사용하도록 구성

컨테이너 실행 시 호스트의 8080번 포트를 컨테이너의 80번 포트에 매핑
```
0.0.0.0:8080->80/tcp
```
```
Mac의 8080 포트
       │
       ▼
Docker 컨테이너의 80 포트
       │
       ▼
      NGINX
```
Mac(호스트 컴퓨터)에서 8080으로 들어온 요청을 컨테이너의 NGINX 80번 포트로 전달(연결)
### localhost:8080을 통한 커스텀 웹 페이지 접속
#### 브라우저에서:
