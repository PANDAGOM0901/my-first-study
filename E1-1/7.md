## Docker 볼륨 영속성 검증

### 개념 정리
#### 바인드 마운트(bind mount)
Mac의 특정 폴더와 컨테이너 내부 폴더를 연결

주목적: 개발 중인 파일을 컨테이너에 바로 반영
#### Docker 볼륨
Docker가 관리하는 별도의 저장 공간

컨테이너를 삭제해도 볼륨을 직접 삭제하지 않는 한 데이터가 남음

주목적: 컨테이너 생명 주기와 별도로 데이터를 영속적으로 보관

### 바인드 마운트 실습
#### html 만들기
site 폴더 안에 index.html 파일 생성
```bash
nano site/index.html
```
다음 내용 입력
```html
<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <title>Bind Mount Test</title>
</head>
<body>
    <h1>Bind Mount 테스트</h1>
    <p>변경 전 내용입니다.</p>
</body>
</html>
```
확인:
```bash
cat site/index.html
```

#### 바인드 마운트 컨테이너 실행
Mac의 site 폴더를 컨테이너의 NGINX 웹 루트에 연결
```bash
docker run -d \
  --name bind-web \
  -p 8080:80 \
  -v "$(pwd)/site:/usr/share/nginx/html" \
  nginx:alpine
```
```bash
  -v "$(pwd)/site:/usr/share/nginx/html"
```
```
  -v: Docker에게 볼륨/디렉터리를 연결해서 사용하겠다는 옵션

  $(pwd)/site: 현재 터미널이 위치한 폴더(pwd) 아래의 site 폴더

  /usr/share/nginx/html: 컨테이너 내부에서 NGINX가 웹 페이지를 읽는 디렉터리
```
```
 iMac의 폴더                         Docker 컨테이너
──────────────────                 ─────────────────────
~/docker-web-workstation/site  →  /usr/share/nginx/html
        ↑                                  ↑
      호스트                              NGINX
```
실행 후 NGINX 컨테이너는 호스트의 site/index.html을 웹 페이지로 사용

Mac 호스트의 파일을 수정한 결과 컨테이너 내부의 NGINX가 제공하는 웹 페이지에도 변경 내용이 즉시 반영되었음

### Docker 볼륨 영속성 실습
이번에는 웹 페이지가 아니라 데이터 파일을 만들어서 컨테이너 삭제 후에도 남아있는지를 확인
#### Docker 볼륨 생성
```bash
docker volume create web-data
```

#### 볼륨을 컨테이너에 연결
Ubuntu 컨테이너를 사용해서 데이터를 저장
```bash
docker run -it \
  --name volume-test \
  -v web-data:/data \
  ubuntu:24.04 \
  bash
  ```

  ```bash
  -v web-data:/data
  ```
  ```
  Docker Volume

    ▼
컨테이너 내부
/data
```

### 최종 정리
바인드 마운트
```
Mac
│
├── site/index.html
│        │
│        │ bind mount
│        ▼
│   /usr/share/nginx/html
│        │
│        ▼
│      NGINX
│        │
└──────► localhost:8080
```
호스트 파일 변경이 컨테이너에 반영

Mac(호스트 컴퓨터)의 파일을 바꾸면
```
Mac 파일 변경
      ↓
컨테이너에 즉시 반영
      ↓
브라우저 새로고침
      ↓
변경 내용 확인
```

Docker 볼륨
```
                Docker
                  │
             web-data
                  │
        ┌─────────┴─────────┐
        ▼                   ▼
   volume-test          volume-test2
      삭제됨                 새로 생성
        │                   │
        X                   │
                            ▼
                    기존 test.txt
                       그대로 존재
```
컨테이너를 삭제했는데도 볼륨 데이터가 유지
