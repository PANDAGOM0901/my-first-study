### 권한 표시 읽는 방법
예를 들어:
```
-rw-r--r--
```
앞의 첫 글자는 파일 종류
```
-  일반 파일
d  디렉토리
```
뒤의 9개 문자는 세 그룹으로 나뉨
```
rw- r-- r--
 │   │   │
 │   │   └─ others(기타 사용자)
 │   └───── group(그룹)
 └──────── owner(소유자)
 ```
 각 문자는 
 ```
r = read    읽기     4
w = write   쓰기     2
x = execute 실행     1
- = 권한 없음
```
따라서
```
rw-r--r--

소유자: 읽기 + 쓰기
그룹:   읽기
기타:   읽기
```
#### rwxd의 의미 및 권한 숫자 표시 방법
권한 숫자는 3자리로 표현
```
rwx
r = 4
w = 2
x = 1
- = 0
rwx = 4 + 2 + 1 = 7
```
예를들어:
```
755
│││
││└─ 기타 사용자(others)
│└── 그룹(group)
└─── 소유자(owner)
```
따라서
```
7    5    5
│    │    │
rwx  r-x  r-x

소유자 → rwx → 읽기 + 쓰기 + 실행
그룹 → r-x → 읽기 + 실행
기타 사용자 → r-x → 읽기 + 실행
```
예를 들어:
```
644
│││
││└─ 4 = r--
│└── 4 = r--
└─── 6 = rw-
```
따라서
```
644 = rw-r--r--

소유자 → rw- → 읽기 + 쓰기
그룹 → r-- → 읽기만
기타 사용자 → r-- → 읽기만
```
### 파일 권한 변경 실습
명령어:
```bash
chmod [권한 숫자 3자리] [파일명]
```
```bash
ls -d [파일명]
```
