## Git 설정 및 GitHub 연동

### Git 사용자 정보/기본 브랜치 설정을 완료하고 git config --list 결과를 기록
#### Git 사용자 정보 설정
```bash
git config --global user.name
```
```bash
git config --global user.email
```
#### 사용자 정보 설정 확인

GitHub 저장소 연동 증거 확인 완료

파일 추가(Git에서 스테이징 영역에 파일 올리기)
```bash
git add .
```
Commit 만들기(스테이징된 파일을 Git 로컬 저장소에 기록)
```bash
git commit -m "커밋 메시지"
```
GitHub로 Push(로컬 commit을 GitHub에 업로드)
```bash
git push origin main
```
Git 상태 확인
```bash
git status
```
